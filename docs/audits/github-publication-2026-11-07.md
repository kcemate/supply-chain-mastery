# Flyway GitHub publication

## Scope and route

User requested pushing the latest Flyway updates to GitHub. Destination verified through authenticated repository metadata: public `kcemate/supply-chain-mastery`. The separate `flyway/decision-intelligence` branch starts from existing GitHub main `83288f0f63fa79900be49dfa5072ac1beee70298`. Existing main and legacy learning assets remain unchanged by this push. The original local checkout and its ChatGPT-hosted `origin` are preserved; `github` is a separate remote.

Route: Git repository tools with otto-os-rails, independently reviewed publication allowlist, isolated managed worktree, and explicit user authorization for GitHub publication. No production deployment, provider configuration, paid API call, merge, force push, or shared-service restart is authorized or performed.

- Current Flyway UI, Decision Intelligence, copilot, typed deterministic simulation, evidence and persistence code.

## Excluded from new changes

Local credentials/configuration, `.env*`, `.herenow` claim state, `.openai` hosting state, caches, backups, generated builds, local service workspaces, unrelated research/audio/day scripts and procurement experiments. The mixed local task and lesson journals were not copied wholesale; only this scoped Flyway checkpoint was added to the existing GitHub task history.

Unfinished CI/container scaffolding is not included: its Docker build omits required public data, and its strict full-browser gate is known to fail. No automatic deployment workflow is added. These unresolved defects are not fixed or hidden by this publication.
